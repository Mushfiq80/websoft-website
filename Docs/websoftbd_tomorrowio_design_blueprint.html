  • Badge pill: "ISO 9001:2015 · BASIS · 18 Years"

Animation approach — light theme version

Instead of dark video, use an animated Canvas or SVG showing Bangladesh weather patterns: slowly rotating radar rings, animated precipitation dots, animated river flow lines on a topographic map. This is domain-specific and far more impressive than generic geometric shapes. Runs at 60fps with requestAnimationFrame.

Key motion patterns from tomorrow.io — adapted for WebsoftBD light theme
Hero animated background
Tomorrow.io: dark cycling video. WebsoftBD light: animated SVG/Canvas showing Bangladesh weather radar rings, animated rainfall grid, river flow paths. Same visual impact, domain-relevant.
canvas + requestAnimationFrame
Scroll-triggered fade-ups
Every section fades up 20px when it enters viewport. Stagger within sections: each child delays 80ms. Used across ALL sections. The single highest-impact animation.
IntersectionObserver + CSS classes
Animated counter numbers
18+ Years, 1000+ Projects, 956 Clients all count up from 0 when scrolled into view. 1.5s duration, easeOut curve. Triggers once per page load.
requestAnimationFrame counter + easing
Client logo marquee
2 rows of client logos scrolling in opposite directions infinitely. Row 1 left at 35s loop, Row 2 right at 45s loop. Pauses on hover. Gives impression of scale.
@keyframes marquee + hover pause
Sector tab transitions
Like tomorrow.io's industry tabs. Click a sector tab → right panel content fades out 0.15s, new content fades in 0.25s. Left accordion slides with max-height. Feels native.
opacity transition + max-height accordion
Dashboard floating visual
BAMIS dashboard screenshot gently floats up and down (translateY ±8px, 4s ease-in-out infinite loop). Drop shadow pulses subtly. Like a product demo floating in air.
@keyframes float + box-shadow pulse
Sticky nav on scroll
Nav starts transparent over hero. After 80px scroll → white bg fades in, box-shadow appears, logo slightly compresses. Smooth 0.3s transition. Standard but essential.
scroll event + CSS transition
Card hover lift
Project and service cards: hover → translateY(-4px) + border-color teal + icon bg change. 0.2s ease. Applied to all cards. Micro-interaction that makes the UI feel responsive.
CSS hover transform + transition
Key difference: light theme motion philosophy
Tomorrow.io uses dark backgrounds where motion is dramatic (glowing planet, dark video). In your light theme, motion should feel calm and data-driven — think gentle fades, precise number counters, and geographic data animations. The hero background should evoke a weather map, not a spacecraft. Color for animation: use teal pulses (#1D9E75), not blue glows.
